## Como rodar localmente

Pré-requisitos:

- Node 20+ (ou ajusta para a tua stack)
- Docker (opcional, se o teu projeto sobe o banco em container)
- Qualquer outra dependência específica

Passos:

```bash
# clonar o repo
git clone https://github.com/seu-user/seu-projeto.git
cd seu-projeto

# instalar dependências
npm install

# subir o ambiente
npm run dev
```

Depois abre `http://localhost:3000` no navegador.

## Decisões técnicas

Conta o que você decidiu e por quê. Não precisa ser longo, precisa
ser sincero. Alguns gatilhos:

- Por que escolheu X em vez de Y?
- O que tentou primeiro e não deu certo?
- O que você aprendeu durante o desenvolvimento?
- Que parte você reescreveu mais de uma vez?
- O que faria diferente se começasse hoje?

A banca valoriza muito ver esse tipo de raciocínio. É o que
diferencia "código que funciona" de "engenharia".
